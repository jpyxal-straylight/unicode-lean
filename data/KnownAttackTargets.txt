# KnownAttackTargets.txt
# Curated inventory of canonical names that have been the target
# of typosquat / homoglyph / supply-chain impersonation attempts
# in published security incidents.  Each row is one canonical
# name, in the case under which the legitimate package / brand
# ships, the HomoglyphConfusable detector uses these as the
# "ground truth" set its confusable-skeleton match should hit.
#
# Curation policy: include only names with a published CVE,
# vendor advisory, peer-reviewed-paper citation, or visible
# typosquat campaign in the ecosystem's public-registry logs.
# No heuristic top-N "popular packages" inclusion — those would
# bloat the table without anchoring to a documented incident.
#
# Format: one canonical name per line, case preserved as the
# legitimate package / brand publishes it; blank lines and `#`
# lines ignored.  Per-name attribution lives in the spec doc, not
# the data file.
